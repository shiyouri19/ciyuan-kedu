# 验收标准与测试清单
版本：0.1

每个阶段完成后，必须运行相关自动化测试，并手工验证本清单中的项目。未通过的验收项不得标记为完成。

## 1. 应用基础
- [ ] Windows 开发环境可启动应用。
- [ ] 生产构建可完成。
- [ ] 首次启动时数据库自动初始化。
- [ ] 关闭并重新打开后，已保存的数据仍存在。
- [ ] 数据库迁移有版本记录；迁移失败时给出错误且不留下半完成结构。
- [ ] 核心番剧库与观看记录功能断网可用。

## 2. 番剧库
- [ ] 可创建手工作品条目。
- [ ] 可编辑标题、年份、类型、简介等字段。
- [ ] 可设置想看、在看、已看完、暂停、弃番状态。
- [ ] 可维护评分、标签、备注和收藏。
- [ ] 可按标题搜索。
- [ ] 可按状态筛选。
- [ ] 作品没有封面、简介或外部 ID 时仍可正常使用。
- [ ] 归档或删除操作有明确确认和影响说明。

## 3. 观看记录
- [ ] 可单集标记已看/未看。
- [ ] 可批量标记指定范围。
- [ ] 可整季标记。
- [ ] 批量操作能清楚展示将影响的集数。
- [ ] 可为历史观看指定日期。
- [ ] 可选择日期不详。
- [ ] 重复标记不会重复计数。
- [ ] 取消已看后统计会正确更新。
- [ ] 误标可以修正。
- [ ] 打开本地视频不会自动标记已看。
- [ ] 记录创建/修改时间与首次观看日期分离。

## 4. 统计
- [ ] 已看集数按不同集计数。
- [ ] 累计标准时长只加总有有效时长的已看集。
- [ ] 未知时长的集仍计入集数。
- [ ] 年度统计按首次观看日期，而不是录入日期。
- [ ] 季度统计按首次观看日期。
- [ ] 日期不详记录不会被误归入当前年份。
- [ ] 页面明确说明统计时长是标准时长估算，不是实际播放时长。
- [ ] 作品状态与单集记录不一致时不会静默互相覆盖。

## 5. 外部元数据
- [ ] 每个 Provider 独立测试。
- [ ] 搜索无结果时有清楚提示。
- [ ] 断网、超时、限流或数据格式异常时应用不崩溃。
- [ ] 有缓存时可显示缓存结果或本地资料。
- [ ] 用户可手动创建和编辑作品。
- [ ] 导入外部资料不会覆盖个人状态、评分、标签、备注和观看历史。
- [ ] 外部 ID 能区分不同来源。
- [ ] 同一作品的候选结果需要用户确认，不能盲目合并。

## 6. 本地媒体
- [ ] 可添加多个媒体根目录。
- [ ] 扫描只新增/更新文件索引，不删除作品或观看历史。
- [ ] 无法解析的文件进入待匹配列表。
- [ ] 匹配结果可由用户确认或修改。
- [ ] 同一集可关联多个版本。
- [ ] 文件丢失后显示 missing，但作品与观看记录保留。
- [ ] 点击可用文件可调用 Windows 默认关联程序。
- [ ] 播放器启动失败时显示错误。
- [ ] 文件移动/改名后可重新定位或重新扫描。

## 7. 资源发现
- [ ] 可新增、编辑、启用/停用资源站点。
- [ ] 搜索关键词被正确 URL 编码。
- [ ] 生成的链接可预览或在外部浏览器打开。
- [ ] 无效模板会提示配置错误。
- [ ] 单一站点失败不影响其他站点。
- [ ] 不绕过登录、验证码、访问控制或站点限制。

## 8. 备份与恢复
- [ ] 可创建备份文件。
- [ ] 备份包含用户个人数据和必要的本地数据库内容。
- [ ] 恢复前提醒用户，并建议备份当前数据库。
- [ ] 错误版本或损坏备份会被拒绝并显示原因。
- [ ] 恢复成功后，作品、观看状态、日期、评分、标签和备注完整。
- [ ] 导出/导入时能处理重复条目并提示冲突。

## 9. 发布前
- [ ] 没有未处理的严重错误。
- [ ] 新安装流程可完成。
- [ ] 数据库路径、备份路径和日志行为清楚。
- [ ] README 包含安装、开发、测试、构建说明。
- [ ] 关键测试在干净环境中通过。
- [ ] 交付说明列出已知问题和未实现功能。
