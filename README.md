# 次元刻度 · 个人动画观看账本 (v0.9.0)

零第三方 npm 依赖（纯 Node.js 22+ 原生 `node:sqlite` + `node:http` + 原生前端），本地优先、支持无黑框独立桌面应用窗口运行，同时预留跨端云同步能力的个人动画观看账本与本地视频文件管理工具。

> 📄 **版本演进与每次改动详情**：请查看项目根目录下的 **[`CHANGELOG.md`](./CHANGELOG.md)**（或 `docs/CHANGELOG.md`）。

## 一、快速启动指南（Windows 日常桌面模式 vs 传统模式）

既然本机已安装 **Node.js 22.5+**，无需安装任何第三方依赖，解压即可使用。我们提供两种启动方式，推荐日常使用**方式 1（无黑框独立桌面窗口）**：

### 方式 1：日常桌面软件模式（无命令行黑框 + 独立应用窗口，推荐 ⭐）
1. **生成桌面图标（仅需首次双击一次）**：
   - 双击项目根目录下的 **`创建桌面快捷方式.vbs`**，系统会在你的电脑桌面上生成 **「次元刻度」** 快捷方式图标。
2. **日常启动**：
   - 直接双击桌面上的 **「次元刻度」** 图标（或双击目录内的 `次元刻度.vbs`）。
   - 启动器会先检查服务是否已在运行；没运行就在后台起服务并等它就绪，起不来会弹窗说明原因并给出日志路径，不会静默失败。
   - **效果**：后台静默启动服务（**全程不弹出任何 cmd 代码黑框**），并自动以 **Edge/Chrome 独立桌面应用窗口（无浏览器地址栏、无标签页）** 打开软件界面；如果后台服务已经在运行，双击图标会直接秒开窗口，不会重复启动进程。
3. **如何安全退出后台服务**：
   - 在软件界面右上角打开 **「设置」** → 点击弹窗左下角的红色 **「退出后台服务」** 按钮；
   - 或者直接双击项目目录下的 **`停止后台服务.bat`**。

### 方式 2：传统调试启动模式（保留命令行日志面板）
- 双击根目录下的 **`启动次元刻度.bat`**（或 `start.bat`），或在终端中运行：
  ```bash
  node --disable-warning=ExperimentalWarning server/index.js --open
  ```
- 默认监听地址：`http://127.0.0.1:7345`

## 二、核心功能全景（Stages 0–16 & P2 完备版）

### 1. 季度新番全量导览、作品详情预览与每日放送周历（Stage 11–16）
- **纯净中文双源聚合（Bangumi + 弹弹Play）**：
  - 移除易产生纯罗马音重复条目的 `AniList` 外文源，聚焦 **Bangumi 番组计划**（自动并发拉取最多 4 页共 200 部 + 当季 `/calendar` 交叉补全）与 **弹弹Play**。
  - **跨源深度去重 (`buildAnimeDedupKeys`)**：自动对齐繁简/日汉字（如 `藥屋少女的呢喃` → `药屋少女的呢喃`）、归一化季度后缀（`第二季 / 第2季 / 第2期 / Season 2 / S2` → `::s2`）并剥离副标题破折号差异，将同番合并为单张卡片（带 `BGM·弹弹` 双源徽章），入库时同步绑定双源外部 ID。
- **未放送 / 提前建档空壳词条精准过滤 (`inspectBangumiBroadcastState`)**：
  - 默认严格过滤开播日晚于今日（`airDate > 今日`）、将开播日暂填为 `01-01 / 04-01 / 07-01 / 10-01` 且 `0 集 + 0 评分` 的占位空壳词条，以及 `PV / CM / 宣传片 / 制作决定` 条目；工具栏支持一键切换「**仅看已开播正片（默认）/ 含未开播预告**」。
- **点击卡片查看「新番作品详情预览」抽屉（Stage 16 新增）**：
  - 默认点击任意新番卡片（或卡片底部的「详情」按钮）即滑出右侧详情预览抽屉，自动异步补全高清封面、中日文原名、开播日、每周放送星期、总集数、评分、分类标签、**完整剧情简介**、**分集标题列表**与外部资源站点快捷检索入口，并支持在抽屉内一键加入「在看 / 想看 / 已看完」。
- **显式「批量选择」开关按钮（Stage 16 新增）**：
  - 点击工具栏右侧的 **「批量选择」** 按钮即可进入多选模式，勾选多部新番后一键批量加入「想看」或「在看」，与日常点击查看详情互不干扰。
- **封面三级自动回退容错（Stage 16 修复）**：
  - 图床白名单全面支持 Bangumi、弹弹Play 与协议相对地址（`//lain.bgm.tv`），支持「缩略图 → 原图 → 代理/直连双通道 → 前端 `no-referrer` 源站直连」多级自动降级，彻底解决新番导览无封面问题。

### 2. 弹弹Play 5 组配额守卫、特别收藏与 365 天打卡热力图（Stage 13）
- **弹弹Play 5 大功能组配额守卫与 90% 自动熔断**：按官方限额实时跟踪「搜索 (100/日)」「番剧详情 (200/日)」「获取弹幕 (100/日)」「发送弹幕 (10/日)」「文件识别 (200/日)」，内置多级持久缓存与 90% 自动熔断保护线。
- **★ 特别收藏与季度评分排序**：支持卡片/抽屉一键星标收藏、顶部「★ 收藏」独立标签页筛选，以及新番导览按评分升降序排列。
- **年度 365 天追番打卡热力图**：统计页展示全年每日追番打卡矩阵、活跃天数、最长连续追番天数（Max Streak）、评分分布、常看题材 Top 榜、最近观看时间轴，并支持一键导出高清 PNG **年度总结海报**与**个人生涯喜好九宫格**。

### 3. 本地视频防踩坑扫描、多版本管理与安全调用播放器（Stage 6–7）
- **字幕组文件名防踩坑清洗管线 (`mediaParser.js`)**：
  - 自动剥离字幕组、分辨率、编码、CRC32 校验码与字幕语言标签；
  - 优先拦截 `NCOP / NCED / PV / CM / Menu` 等特典文件，严防 `NCOP1` 被误判为正片第 1 集；
  - 保护 `86 -Eighty Six-` 等数字番名；对同系列剧场版负样本自动降权；对 `S02+` 跨季文件且库内仅有第 1 季时自动归入 `needs_review` 待确认队列，绝不静默绑错季度。
  - 支持ローマ字（罗马音）文件名自动转中文番名并一步补齐封面与元数据，支持直接入库第 3 季（不产生幽灵第 1 季）。
- **常驻媒体根目录与安全调用系统播放器**：
  - 支持同一集关联多个分辨率版本、文件移动自动重定位、文件缺失保留观看记录；
  - 通过参数数组安全调用系统默认关联播放器打开视频，且严格遵守规范：**打开本地视频绝不自动标记已看**。

### 4. 核心账本、多季/SP管理、手工字段锁与 16 表物理备份（Stages 0–10 & P2）
- **16 张表完整数据架构 (`user_version = 4`)**：
  - 核心表：`anime`、`user_anime_state`、`seasons`、`episodes`、`episode_watch_state`、`tags`、`anime_tags`、`app_settings`、`external_ids`
  - 扩展与 P2 表：`anime_aliases`（作品别名）、`library_roots`（媒体根目录）、`media_files`（视频文件索引）、`resource_providers`（检索模板）、`anime_metadata_fields`（手工编辑字段锁定防覆盖）、`resource_items`（站内 RSS 按字幕组分栏缓存）、`watch_events`（观看操作时间轴）
- **严格遵守合规红线**：
  - **D-001**：统计严格按每集首次观看日期（`first_watched_at`）归类。
  - **D-002**：未知单集时长严格保持 `null`，计入已看集数但不伪造观看时长（绝不硬编码 24 分钟）。
  - **FR-02**：卡片点击 `+1` 到最后一集时弹窗询问确认，绝不后台静默篡改作品状态。
- **SQLite 16 表全量物理备份与恢复 (`backupService.js`)**：支持一键创建物理快照、SQLite 文件头与 `PRAGMA integrity_check` 校验、恢复前自动生成 `pre-restore` 备份，以及支持 `sync` / `merge` / `skip` 三种冲突策略的 JSON 导入导出。
